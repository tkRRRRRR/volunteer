# 数据库设计说明

首版数据库包含 5 个核心实体。

| 表 | 作用 | 关键字段 |
| --- | --- | --- |
| `sys_user` | 学生与管理员账号 | 用户名、密码哈希、角色、省份、科类、分数、位次 |
| `university` | 院校基础信息 | 名称、省份、城市、层次、类型、标签 |
| `major` | 院校开设专业 | 所属院校、专业名称、门类、选科要求 |
| `admission_record` | 历年录取记录 | 院校、专业、省份、年份、科类、最低分、最低位次、来源 |
| `favorite` | 学生收藏 | 用户、院校、专业 |

## 关系

- 一所院校包含多个专业。
- 一条录取记录对应一所院校，可选对应一个专业。
- 一个用户可以收藏多个院校专业。
- 收藏记录通过用户 ID 隔离，学生不能删除他人的收藏。

## 数据注意事项

所有正式录取数据都必须保留省份、年份、科类、批次和来源。当前初始化数据全部标记为“演示数据（非官方）”，不能用于真实志愿填报结论。

不同年份的最低分不能直接横向比较。推荐时以最低位次为主要指标，分数差异作为辅助指标。
