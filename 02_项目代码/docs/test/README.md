# 测试记录

## 当前自动化测试

`RecommendationScorerTest` 覆盖以下情况：

- 位次更强时匹配分更高。
- 位次和分数明显领先时归类为保底。
- 位次和分数明显落后时归类为不建议。
- 位次输入不合法时拒绝计算。

运行命令：

```powershell
cd volunteer-backend
mvn test
```

`UniversityServiceImplTest` 覆盖院校详情聚合、空专业和空录取记录、院校不存在以及省份和科类筛选条件。

`AdminCatalogServiceImplTest` 覆盖：

- 专业新增、筛选、更新和删除。
- 跨院校专业归属校验。
- 录取记录分页筛选、新增、更新和删除。
- 专业必填、未来年份和重复录取记录校验。
- 被录取记录或收藏引用的专业删除保护。

`AdmissionFileParserTest` 覆盖：

- UTF-8 BOM、乱序表头和引号字段。
- `.xlsx` 数字与公式单元格。
- `.xls` 旧格式工作簿。
- 空行真实行号。
- 空文件、未知扩展名、缺列、重复列和 1000 行限制。

`AdmissionImportServiceImplTest` 覆盖：

- 合法行部分成功和错误行反馈。
- 专业归属、名称匹配和字段范围。
- 文件内重复和数据库重复。
- 文本清理、院校不存在。
- Excel 模板内容和无专业提示。

## 前端单元测试

前端使用 Vitest 测试纯数据转换，不依赖浏览器：

- 院校趋势图：三年分数序列、三年位次序列、专业过滤和空状态。
- 收藏对比：2 至 4 项选择限制、最近录取点选择和单个详情失败时的降级展示。
- 管理端数据维护：专业文本清理、录取表单数字转换、筛选参数清理、无专业时禁用新增和默认演示来源。
- 批量导入：CSV/XLSX/XLS 扩展名、2 MB 大小边界和文件大小格式化。

运行命令：

```powershell
cd volunteer-frontend
npm run test:unit
npm run build
```
