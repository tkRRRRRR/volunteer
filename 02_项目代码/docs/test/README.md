# 测试记录

## 当前自动化测试

`RecommendationScorerTest` 覆盖以下情况：

- 位次更强时匹配分更高。
- 位次和分数明显领先时归类为保底。
- 位次和分数明显落后时归类为不建议。
- 位次输入不合法时拒绝计算。

运行命令：

```powershell
cd volunteer-backend
mvn test
```
