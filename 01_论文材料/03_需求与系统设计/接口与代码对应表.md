# 接口与代码对应表

## 后端接口

| 功能 | 接口 | Controller | 主要服务 |
| --- | --- | --- | --- |
| 学生注册 | `POST /api/auth/register` | `AuthController` | `AuthServiceImpl` |
| 登录 | `POST /api/auth/login` | `AuthController` | `AuthServiceImpl` |
| 获取档案 | `GET /api/auth/profile` | `AuthController` | `AuthServiceImpl` |
| 更新档案 | `PUT /api/auth/profile` | `AuthController` | `AuthServiceImpl` |
| 院校分页 | `GET /api/universities` | `UniversityController` | `UniversityServiceImpl` |
| 院校详情 | `GET /api/universities/{id}` | `UniversityController` | `UniversityServiceImpl` |
| 院校专业与趋势 | `GET /api/universities/{id}/overview` | `UniversityController` | `UniversityServiceImpl` |
| 冲稳保筛选 | `POST /api/recommendations` | `RecommendationController` | `RecommendationServiceImpl` |
| 收藏列表 | `GET /api/favorites` | `FavoriteController` | `FavoriteServiceImpl` |
| 新增收藏 | `POST /api/favorites` | `FavoriteController` | `FavoriteServiceImpl` |
| 取消收藏 | `DELETE /api/favorites/{id}` | `FavoriteController` | `FavoriteServiceImpl` |
| 院校维护 | `/api/admin/universities` | `AdminUniversityController` | `UniversityServiceImpl` |
| 专业维护 | `/api/admin/universities/{id}/majors` | `AdminCatalogController` | `AdminCatalogServiceImpl` |
| 录取记录维护 | `/api/admin/universities/{id}/admission-records` | `AdminCatalogController` | `AdminCatalogServiceImpl` |
| CSV/Excel 导入 | `/api/admin/universities/{id}/admission-records/import` | `AdminAdmissionImportController` | `AdmissionImportServiceImpl` |
| Excel 模板 | `/api/admin/universities/{id}/admission-records/import-template` | `AdminAdmissionImportController` | `AdmissionImportServiceImpl` |
| 管理统计 | `GET /api/admin/statistics/overview` | `AdminStatisticsController` | `AdminStatisticsServiceImpl` |
| 学生账号 | `GET /api/admin/students` | `AdminStatisticsController` | `AdminStatisticsServiceImpl` |

## 代码目录

| 层次 | 目录 | 作用 |
| --- | --- | --- |
| 后端入口 | `volunteer-backend/src/main/java/com/example/volunteer` | Spring Boot 应用 |
| 控制器 | `controller/` | HTTP 请求与参数入口 |
| 服务接口 | `service/` | 业务能力定义 |
| 服务实现 | `service/impl/` | 权限、校验、查询和事务逻辑 |
| 数据实体 | `entity/` | 对应数据库表 |
| Mapper | `mapper/` | MyBatis-Plus 数据访问 |
| DTO | `dto/` | 请求参数和校验 |
| VO | `vo/` | 页面返回数据 |
| 文件解析 | `service/importing/` | CSV/Excel 解析 |
| 前端页面 | `volunteer-frontend/src/views/` | 登录、学生端和管理端页面 |
| 前端组件 | `volunteer-frontend/src/components/` | 管理端复用组件 |
| 请求封装 | `volunteer-frontend/src/api/` | Axios 接口调用 |
| 前端工具 | `volunteer-frontend/src/utils/` | 图表、表单和权限辅助函数 |

| 页面 | 路由 | 角色 |
| --- | --- | --- |

| 冲稳保筛选 | `/recommendations` | 学生 |
