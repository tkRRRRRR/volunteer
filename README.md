## 推荐技术栈

后端使用 Java 17、Spring Boot 3、Maven、Spring MVC、MyBatis-Plus、MySQL 8、Redis、JWT、Bean Validation 和 OpenAPI。前端使用 Vue 3、Vite、JavaScript、Vue Router、Pinia、Axios、Element Plus 和 ECharts。开发和测试使用 Git、Postman 或 Apifox、JUnit 5、Mockito。

这套方案保留了前后端分离、缓存、权限控制、接口文档和自动化测试等毕业设计常见内容，同时避免引入 Spring Cloud、微服务、消息队列、搜索引擎和复杂机器学习模型。

## 项目边界

系统提供院校专业查询、历年录取数据展示、个人成绩与位次管理、冲稳保辅助筛选、收藏对比管理、后台数据维护等功能。推荐结果定位为基于历史数据的辅助匹配，不承诺录取，也不宣称能够准确预测录取概率。

院校录取数据必须说明来源、年份、省份、科类或选科要求及批次。没有可靠数据时使用明确标注的演示数据，不编造真实录取结论。

## 第一阶段的完成标准

先完成学校模板收集、需求边界确认、系统原型、数据库初稿和开题报告。代码先打通登录、院校查询、个人档案、推荐筛选和后台数据管理这一条主流程，再补充缓存、统计图和测试。论文中的架构、功能、数据库和测试内容应与实际代码保持一致。

## 便携开发环境

所有开发运行库统一放在 `dev-environment/`。首次配置：

```powershell
Set-Location .\dev-environment
.\setup-environment.ps1
.\start-all.ps1
```

完整配置教程见 `dev-environment/README.md`。环境包含固定版本的 JDK、Maven、Node.js、MySQL、Redis、项目专用 Maven 依赖缓存、数据库数据和启动验证脚本。

大型运行时、数据库数据、日志和缓存不进入 Git 历史；复制整个项目文件夹时可一并保留，从 Git 克隆后再运行 `setup-environment.ps1` 自动重建。

项目代码使用必要的中文注释，重点解释业务流程、算法依据、安全判断和非直观实现。Git 提交信息统一使用中文，推荐格式为“类型：中文简述”。

完整要求见 `CONTRIBUTING.md`。仓库提供 `.gitmessage-zh` 提交模板，可通过以下命令启用：
